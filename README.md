# PSB Tuition website

A fast, mobile-friendly static website (HTML, CSS and JavaScript). There is no build step.

## Update your details
Open `script.js` and edit the `CONFIG` block at the top: phone, WhatsApp number, email, address and class timings. The page updates automatically.

## Publish on GitHub Pages
1. Go to **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `master` branch and the `/ (root)` folder, then **Save**.
4. After a minute the site is live at `https://<your-username>.github.io/psb/`.

## Edit content
- Text, subjects and FAQs: `index.html`
- Colours and fonts: the variables at the top of `styles.css`
